# BlastSimulator

Interactive blast map: pick a weapon and a location and see the effect zones (fireball, blast, thermal and initial radiation), an animated explosion with damage and fires, and an estimate of casualties based on real population data.

- Nuclear weapons, conventional explosions (e.g. Beirut 2020) and fictional scenarios
- Map and satellite view, 3D buildings that collapse with the shock wave
- Metric or imperial units, shareable scenario links

Sources and methodology are listed on the site (“Sources & methodology”). Maps © MapTiler © OpenStreetMap contributors. Population: GHSL GHS-POP R2023A, © European Union (JRC). Place search: Natural Earth.
