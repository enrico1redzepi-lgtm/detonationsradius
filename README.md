# Detonationsradius

Interaktive Karte, die die Wirkungszonen einer Kernexplosion zeigt (Feuerball, Druckwelle, Hitze, Strahlung) – mit animierter Explosion, Karten- und Satellitenansicht.

Radien nach den Skalierungsgesetzen aus Glasstone & Dolan (1977). Karten: MapTiler, OpenStreetMap-Mitwirkende. Ortssuche: Natural Earth.
